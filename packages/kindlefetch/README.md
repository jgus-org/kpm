# KindleFetch

KindleFetch requires [kTerm](https://github.com/bfabiszewski/kterm) at `/mnt/us/extensions/kterm`. It opens its terminal interface through the Kindle Library item.

Run its setup before searching. Downloads default to `/mnt/us/documents`; you may choose another directory on the Kindle USB drive. Z-Library access is optional and requires credentials you provide in KindleFetch. This package disables the upstream self-updater; update KindleFetch through KPM.

See the [upstream project](https://github.com/justrals/KindleFetch) for supported sources and service requirements.
