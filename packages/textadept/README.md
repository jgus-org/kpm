# Textadept

Textadept 12.9.2 is a programmable text editor with terminal and graphical interfaces. Open it from the Kindle Library; this package starts the terminal interface through [kTerm](https://github.com/bfabiszewski/kterm), which is more responsive on e-ink displays.

Textadept stores preferences, sessions, and user Lua modules in `/mnt/us/.textadept`. KPM does not install, replace, or remove that directory. Your text files remain wherever you save them.

An external keyboard is recommended. The optional [Kindle HID Passthrough](https://github.com/kbarni/kindle-hid-passthrough) project can provide Bluetooth keyboard support. Read the bundled manual or the [upstream Textadept port](https://github.com/kbarni/textadept-kindle) for shortcuts, configuration, and the graphical launch option.
