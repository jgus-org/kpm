# RAnki

RAnki stores Anki collections and downloaded media in `/mnt/us/anki_data`. KPM leaves that directory in place when the package is updated or removed. Its local `config.ini` is also retained, including custom sync-server settings.

Open RAnki from the Kindle Library and configure sync in the application. RAnki provides a Kindle client; it does not include card decks.

See the [upstream project](https://github.com/crazy-electron/ranki) for syncing, media, and MathJax support.
