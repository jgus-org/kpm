# Gnome Games Suite

Gnome Games Suite provides Gnome Chess and Gnome Mines. Installation adds a separate Kindle Library item for each game. `;kpm launch gnomegames` starts Chess; `;kpm launch gnomegames mines` starts Mines.

The package includes the ARM hard-float and ARMEL programs from upstream release 1.1 and selects the matching program on the Kindle. No game ROMs or other user-supplied files are required.

Source is available from the [Gnome Games for Kindle project](https://github.com/crazy-electron/GnomeGames4Kindle). The suite includes Stockfish and Gnome GNU Chess engines with their upstream game payload.
