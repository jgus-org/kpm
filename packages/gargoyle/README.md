# Gargoyle

Gargoyle installs interpreters, not interactive-fiction games. Unpack ZIP downloads, then copy story files to `IF` at the root of the Kindle USB drive (`/mnt/us/IF`; create the folder if it is absent). Launch Gargoyle and select a Z-machine (`.z3`, `.z5`, `.z8`, `.zblorb`) or Glulx (`.ulx`, `.gblorb`) story.

See the [Gargoyle website](https://ccxvii.net/gargoyle/) and [upstream project](https://github.com/garglk/garglk).

[IFDB](https://ifdb.org/) catalogs games and their download pages. The [Interactive Fiction Archive](https://www.ifarchive.org/) preserves downloadable games and tools.
